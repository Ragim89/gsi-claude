# 04. Медиа (фото/видео) и генерация отчётов на бланке

- В полевом чек-листе инспектор прикрепляет фото/видео к каждому пункту (напр. «Состояние трюма», «Пломбы», «Проба зерна») — автоматический таймштамп, GPS, привязка к `job_id`.
- Хранение — объектное хранилище, S3-совместимое (MinIO self-host или облако). Оригиналы хранятся для аудита ISO 17020, превью/сжатое видео — для быстрого просмотра в UI.
- Отчёт компонуется из шаблона филиала (лого, реквизиты, язык) + данные инспекции + встроенная галерея фото + подпись супервайзера + QR-код для верификации подлинности третьей стороной.
- Рендер PDF: HTML-шаблон на филиал → headless Chromium/Puppeteer, либо DOCX-шаблонизатор (Carbone/DocxTemplater) → экспорт в PDF.
- **Экспорт по контрагенту**: в карточке клиента — кнопка «Выгрузить все отчёты и результаты анализов за период» → сводный PDF/Excel или ZIP-архив отдельных PDF, на бланке нужного филиала.

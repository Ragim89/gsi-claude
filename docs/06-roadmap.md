# 06. Дорожная карта

| Этап | Содержание | Ориентир |
|---|---|---|
| MVP-1 | Ядро: контрагенты, заявки на инспекцию, полевой чек-лист с фото, генерация PDF-отчёта на бланке 1–2 филиалов (Турция + один регион), базовые роли, аутентификация | 6–8 недель |
| MVP-2 | Мультиязычность (минимум EN/RU/TR), мультивалютный биллинг, базовый LIMS-модуль | +4–6 недель |
| MVP-3 | Финансовый дашборд в реальном времени, консолидация по всем 7 юрлицам, клиентский портал | +4–6 недель |
| Расширение | Мобильное офлайн-приложение, RTL/арабский, полный compliance-модуль ISO 17020/17025, интеграции (банк-клиент, бухгалтерия по странам) | далее |

## Порядок реализации MVP-1 (для первой агентной сессии)
1. Инициализация монорепо (`apps/api`, `apps/web`, `packages/ui-kit`, `packages/shared-types`).
2. Схема БД: `branches`, `users`, `clients`, `inspection_jobs`, `job_checklist_items`, `media_attachments`, `reports`.
3. Auth + роли (инспектор, супервайзер, админ).
4. CRUD: контрагенты, заявки на инспекцию.
5. Полевой чек-лист (веб-версия для начала) с загрузкой фото.
6. Генератор PDF-отчёта по одному шаблону (Турция) с токенами цвета из 00-overview.md.
7. Базовый список отчётов по клиенту с выгрузкой PDF.

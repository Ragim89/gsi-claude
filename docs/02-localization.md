# 02. Локализация и мультиязычность

- i18n на уровне UI через ключи: `en.json, ru.json, tr.json, uk.json, it.json, ro.json, uz.json, kk.json, ar.json`, fallback на en.
- RTL-поддержка для арабского (офис ОАЭ) — заложить в UI-кит с первой версии (дороже переделывать потом).
- Локализация данных, не только интерфейса:
  - формат даты/времени/чисел по локали филиала
  - налоговые ставки/формы по стране (НДС/КПН)
  - разные реквизиты печатной формы отчёта по стране (QR, печать, подпись — уточнить у GSI по каждому филиалу)
  - Row-Level Security — пользователь видит данные только своего филиала
- Единый глоссарий терминов (Draft Survey, Sampling, Fumigation и т.д.) — переводится один раз, переиспользуется в UI и в шаблонах отчётов.

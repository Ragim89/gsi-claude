# 07. Открытые вопросы к GSI перед/во время разработки

1. Официальный брендбук / векторный логотип с точными HEX-кодами.
2. Точный список юридических лиц и действующие учётные системы в каждой стране (нужна ли миграция данных).
3. Обязательный набор языков интерфейса (vs. опциональные).
4. Действующие шаблоны отчётов/сертификатов по каждому филиалу (для точного бланка).
5. Нужна ли интеграция с внешними системами (банки, локальная бухгалтерия по странам, реестры GAFTA/FOSFA).

> Claude Code: если в процессе работы возникает решение, зависящее от ответа на один из этих вопросов — делай разумное предположение, явно фиксируй его в коде/коммите комментарием `// ASSUMPTION:` и продолжай, не останавливая работу.

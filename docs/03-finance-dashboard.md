# 03. Финансовый дашборд в реальном времени

Доступен ролям CFO/HQ, обновляется без перезагрузки (WebSocket/SSE, событийная модель, не polling).

## Метрики
- **Капитализация группы** — суммарные активы по всем 7 юрлицам, консолидированные в единой валюте (EUR/USD), с разбивкой по странам.
- **P&L** — по группе и по филиалу, план/факт, тренд по месяцам/кварталам.
- **Доход/расход** — по видам услуг (Weight Supervision, Lab Testing, Fumigation и т.д.), по клиентам, по филиалам.
- **Cash Flow** — входящие/исходящие платежи, дебиторка/кредиторка, просрочки.
- **Операционные KPI рядом с финансовыми**: число инспекций за период, средний срок заявка→отчёт, загрузка инспекторов.

## Техническая механика
1. Событие (утверждён счёт / поступила оплата / добавлен расход) сразу пишется в `ledger_entries`.
2. Агрегаты дашборда пересчитываются инкрементально (не полным пересчётом БД при каждом обновлении).
3. Фронтенд получает обновление через WebSocket (Socket.IO) или SSE.
4. Мультивалютная консолидация — конвертация по `fx_rates` на дату проводки, хранить сумму в валюте филиала И в валюте консолидации.

# IMPLEMENTATION_PLAN — план доведения GSI ONE до production

Основан на аудите [`CURRENT_STATE.md`](CURRENT_STATE.md). Статусы: **DONE** / **IN PROGRESS** / **TODO** / **BLOCKED**.

Правило работы: каждая фаза — полный вертикальный срез (миграция → сервис → API → права → аудит → UI → тесты → документация). Фаза не считается завершённой, пока не проходят сборка и тесты.

Как именно фаза выполняется и чем заканчивается — в [`AI_EXECUTION_RULES.md`](AI_EXECUTION_RULES.md).

## Приёмочный сценарий

Считается выполненным только целиком, от начала до конца, на чистой базе:

1. Admin создаёт страну → 2. офис → 3. пользователя → 4. назначает роль → 5. Sales создаёт клиента → 6. Operations создаёт заявку → 7. Office Manager назначает инспектора → 8. Inspector видит заявку на телефоне → 9. начинает инспекцию → 10. загружает фото → 11. заполняет чек-лист → 12. создаёт образец → 13. завершает инспекцию → 14. лаборатория принимает образец → 15. аналитик вводит результаты → 16. Lab Manager утверждает → 17. Report Reviewer готовит отчёт → 18. Manager утверждает → 19. система выпускает финальную версию → 20. Finance выставляет счёт → 21. регистрируется оплата → 22. заявка закрывается → 23. результат виден в аналитике → 24. все критичные действия видны в журнале аудита.

Текущее состояние сценария: шаги 5, 6, 7, 9–11, 13, 14, 15, 16, 17, 18, 19, 20, 21, 23 работают; остальные требуют реализации.
